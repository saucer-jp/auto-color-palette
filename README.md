# Auto Color Palette

基準HUEとOKLCHの彩度・明度カーブを指定して、カラーパレットを生成する静的Webアプリです。表示色はsRGBのHEXに統一し、ブラウザ間の色域マッピング差を抑えます。

## Features

- 基準HUE: 0〜359.9°
- 色相数: 2〜24
- カラーステップ: 5〜30
- OKLCH Cの3点カーブ（縦軸は0〜100%固定）
- OKLCH Lのカスタム3点カーブとS字カーブを切り替え可能（S字も始点・中点・終点をカーブのつまみで設定）
- Grid gap: 0〜40px
- パレット背景色を変更可能
- 色相は360°を均等分割
- グレースケール列を左側に配置
- グレースケールの右に、色相と彩度の影響度を調整できる色付きグレー列を表示
- 基準HUEとC/Lカーブを基準に各スウォッチを生成
- 左端の基準列の明るさ（OKLab L）に合わせ、各行の全色相でsRGB内に収まる最大の共通彩度（OKLCH C）を求めて、カラー表示の明るさ・鮮やかさを揃える
- グレースケール表示（開発用）は色を置き換えず、生成された色付きスウォッチをCSSフィルターで確認する診断モード
- パレットをクリックすると描画色のHEX値をコピー
- 設定値はURLに反映され、設定パネルのリンクアイコンから共有可能
- 設定値はブラウザのlocalStorageにも保存
- sRGBの制約で行全体の彩度を下げたスウォッチには警告ドットを表示（localhost限定の開発用）
- 開発用にプレビューをグレースケール表示するチェックボタン
- 「均質さ ↔ 鮮やかさ」のトーンバランスを調整するスライダー（0〜100）
- 設定パネル右上のアイコンから、色相ごとにグループ化したJSONをプレビュー・コピー
- 表示色は最終的なsRGB HEXに統一し、ブラウザごとの色域マッピング差を抑制
- システムのライト/ダーク設定に対応

## トーンの揃え方

彩度カーブは各行で使うCの上限です。以下はトーンのバランスが0の場合の挙動で、値を上げると色相ごとの彩度を一部戻します。その明るさでは指定彩度を表示できない色相がある場合、行全体を同じCまで下げます。色相ごとに別々に彩度を落とすと、Lが等しくても鮮やかな色とくすんだ色が混在するためです。共通彩度の範囲内では指定値をそのまま使い、明るさと色相を保ちます。このため、従来より一部の色が落ち着いた見た目になり、共通の色域上限を超えて彩度カーブを上げても出力は変わりません。

基準は[OKLabの明るさと彩度](https://bottosson.github.io/posts/oklab/)です。[明るさ・色相を保つ色域調整](https://bottosson.github.io/posts/gamutclipping/)を行全体に適用します。最終HEXの8bit丸めによる差は残り、特に黒に近い色では表現できる階調が少ないため差が大きくなります。また、OKLabは知覚の近似であり、背景・観察環境・個人差を含む見た目の完全一致を保証するものではありません。

開発用のCSSグレースケール表示はsRGBチャンネルの加重和を使う診断表示で、カラーの見え方をそのまま評価する指標ではありません。グレースケールの一致は生成条件にせず、テストでは最終HEXから計算した各行のLとCのばらつき、およびsRGB色域内に収まることを確認します。

### トーンのバランス

設定パネルに「トーンのバランス」を表示します。0は共通彩度による統一、50は初期値、100は制限内で最も鮮やかさを戻す設定です。100でも色相別の最大彩度をそのまま使うわけではありません。

明度L・色相Hを固定したまま、各色相でsRGB内に収まる彩度を求め、共通彩度からの差を一部だけ戻します。0〜50では従来の復元量を維持します。50を超えると復元強度と明暗端の復元範囲を滑らかに広げ、100では強度を従来の最大値の2倍にします。このため高い設定ほど鮮やかさが増し、行内の彩度差も大きくなります。

復元量の基準は共通Cの75%かつ絶対Cで0.08です。スライダー値を0〜1の `r` としたとき、`b = max(0, 2r−1)²` とし、復元強度を `r+b`、明度による重みを `(4L(1−L))^(2−b)` とします。100では復元量の上限が共通Cの150%かつ絶対Cで0.16となり、重みは `4L(1−L)` です。白・黒に近い行の復元は引き続き抑え、最終的に指定彩度と各色相のsRGB限界で制限します。いずれもカラー表示で比較するための暫定的な設計値で、知覚的な許容差の規格値ではありません。

調整は描画・スウォッチのコピー・JSON出力のすべてに反映されます。値はlocalStorageと共有URLの `toneBalance=0〜100` に保存され、「設定を初期値に戻す」で50に戻ります。旧保存設定・旧共有URLで値がない場合は、従来の色を保つため0を引き継ぎます。localhostの旧 `devChromaRecovery` URLは新しい設定に移行します。グレースケール表示と色域調整の警告ドット表示はlocalhost限定の開発用機能です。

## 色付きグレー

色付きグレー列は通常のグレースケール列のすぐ右に表示します。グレースケールと同じ明度カーブ・ステップを使い、色相は専用のスライダーで独立して調整できます。彩度の影響度は0〜100%で、初期値は30%です。0%ではグレースケールと同じ無彩色になります。100%でも、色付きグレーの彩度は各行の共通彩度の15%またはOKLCH C 0.02の小さい方までに抑えます。さらに選択した色相とその明度でsRGB内に収まるよう彩度を調整します。この列は全体のトーンに沿う、ごく淡い色の参考列です。

旧保存設定や共有URLに専用色相が含まれない場合は、その時点の基準色相を引き継ぎます。色付きグレーの色相と彩度の影響度はlocalStorageと共有URLの `tintedGrayHue`・`tintedGrayInfluence` に保存されます。JSON出力には `tintedGrayscale` として色相・HEX一覧を含めます。既存の `grayscale` と `hues` の意味は変わりません。

## Run locally

ビルド不要です。ローカルサーバーで配信してください。

~~~sh
python3 -m http.server 4173
~~~

ブラウザでhttp://localhost:4173を開きます。
